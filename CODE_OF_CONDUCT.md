# Code of Conduct

SRTL Manager should be a focused, respectful place to build reliable software.

## Expected Behavior

- Discuss ideas and defects directly without attacking the people involved.
- Give actionable technical feedback and assume honest mistakes.
- Respect privacy. Do not post credentials, private paths, logs, inventory data, or personal information.
- Accept reasonable maintainer decisions about scope, safety, and release timing.

## Unacceptable Behavior

Harassment, threats, discriminatory language, deliberate disruption, publishing another person's private information, and repeated personal attacks are not permitted in project spaces.

## Enforcement

Maintainers may edit or remove content, close discussions, reject contributions, or temporarily or permanently restrict participation when necessary. Enforcement decisions will consider context, severity, and repeated behavior.

Report conduct concerns privately to a maintainer when a private contact method is available. If none is listed, open a minimal issue requesting private contact without including sensitive details in public.

This policy applies to repository issues, pull requests, reviews, discussions, and other spaces where someone represents the project.
